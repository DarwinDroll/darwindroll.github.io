# Darwin Igemonas Droll — personal website

A responsive static rebuild of the supplied darwindroll.com archive. No build
step, JavaScript, framework, external fonts, analytics or contact-form service
is required.

## Pages

- [Home](index.html): mission, values, seven technologies and all 14 certifications.
- [Imprint](imprint.html): operator and contact details from the archive.
- [Data protection](datenschutz.html): privacy information for the static site.

The homepage contact buttons link directly to `mailto:contact@darwindroll.com`.

All pages use [style.css](style.css). Original imagery and technology logos are
stored in [images/](images/); no image is hotlinked to Squarespace.

## Preview and publish

Open `index.html` directly in a browser, or serve this directory with any static
web server. Relative links work both locally and under a GitHub Pages subpath.

For GitHub Pages, publish the repository root from your chosen branch in
**Settings → Pages**. No generated output directory is needed. This change does
not configure a custom domain or alter DNS.

## Content and legal review

The archive is the source of the homepage text, email addresses, certifications,
address and telephone number. Minor spelling and grammar corrections
have been made, without adding qualifications or updating employment claims.

Before publishing, confirm that those archived details are still current and
that you have the rights to publish the supplied imagery. Product logos belong
to their respective owners.

The German legal pages are a starting point, not legal advice. The imprint uses
current DDG/MStV references instead of the archive's TMG/RStV references. The
privacy text assumes GitHub Pages hosting and an email-only contact workflow;
it deliberately omits the archive's Squarespace, Google Analytics and AdSense
boilerplate because these integrations are not present. Verify the actual host,
its retention and international-transfer arrangements, your email provider and
any applicable legal requirements before going live. Update the policy if the
hosting or data processing changes.
